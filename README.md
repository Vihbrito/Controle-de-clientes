# 💰 Controle de Débitos de Clientes - Django App

Uma aplicação web desenvolvida com **Python + Django** para gerenciamento de clientes que compram fiado 🧾. Com esta ferramenta, estabelecimentos comerciais podem manter o controle de:

- ✅ Clientes cadastrados
- 🛒 Compras realizadas (com descrição, valor e data)
- 📅 Vencimentos mensais para cobrança



## ✨ Funcionalidades

- 📇 Cadastro de clientes com nome
- 🧾 Registro de compras (produto, valor, data)
- 📆 Vencimento mensal automático por cliente
- 🔍 Visão geral de débitos pendentes
- 📤 Atualização e quitação de débitos


## 🛠️ Tecnologias Utilizadas

- 🐍 Python 3.x
- 🌐 Django 4.x
- 🗃️ SQLite (padrão Django para desenvolvimento)
- 🎨 Bootstrap (para estilização básica)
